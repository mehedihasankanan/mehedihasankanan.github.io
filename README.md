# Mehedi Hasan Kanan — Personal Website

A responsive bilingual (English/Bangla) personal website and engineering portfolio.

## Publish with GitHub Pages
1. Upload all files and folders to the root of `mehedihasankanan.github.io`.
2. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`.
3. Wait for deployment, then visit `https://mehedihasankanan.github.io`.

## Before publishing
- Replace `YOUR_EMAIL@example.com` in `index.html`.
- Replace the LinkedIn URL with your actual profile URL.
- Add your portrait as `assets/profile.jpg` (then update the placeholder in `index.html` if desired).
- Add your CV as `assets/cv.pdf` and add a download link.
- Verify job title, employer name, education and project details before making them public.

This is a static website: your laptop does not need to stay on after GitHub Pages publishes it.
